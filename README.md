## 🚀 Run Locally

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/vijayg963/Portfolio_me.git
cd Portfolio_me
npm install
npm run dev
```

Open the local Vite development URL shown in your terminal.

### Production build

```bash
npm run build
npm run preview
```

### Lint

```bash
npm run lint
```
